# Security Policy

## Reporting a vulnerability

If you discover a security issue in this example app or the Binoban SDK, please report
it privately:

- Email **security@binoban.io**
- Do **not** open a public GitHub issue for security vulnerabilities.

Please include enough detail to reproduce the issue. We will acknowledge your report and
keep you updated on remediation.

## Credentials

This is a public reference app and contains **placeholder credentials only**
(`YOUR_API_KEY`, `YOUR_SOURCE_IDENTIFIER`, `YOUR_API_HOST`). Never commit real API keys,
source identifiers, or non-production hosts. Keep `local.properties` out of version
control. Request credentials for your account from **support@binoban.io**.
